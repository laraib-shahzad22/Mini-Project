# 🍰 SweetCrumbs – Bakery Management System

SweetCrumbs is a React Native mobile application designed to help bakery owners and staff manage their daily bakery operations efficiently.

## ✨ Features

- Dashboard with bakery overview
- Product and inventory management
- Add, update and manage bakery products
- Customer order management
- Billing and receipt generation
- Sales history and recent orders
- Local database storage using SQLite

## 🎨 Design

- Chocolate Brown
- Caramel
- Cream

A clean, attractive and user-friendly mobile interface.

## 🛠️ Technologies Used

- React Native
- JavaScript
- SQLite
- React Navigation
- Android Studio

## 📱 Platform

Android

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/laraib-shahzad22/Mini-Project.git
```

Navigate to the project directory:

```bash
cd Mini-Project
```

Install dependencies:

```bash
npm install
```

Start Metro:

```bash
npm start
```

In another terminal, run:

```bash
npm run android
```
